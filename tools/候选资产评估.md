# 工具库候选资产评估

## 首批已整理

| 资产 | 入选理由 | 公开前状态 |
|---|---|---|
| `paper-exam-to-md-pdf` | 覆盖扫描件到 Markdown/PDF 的主流程，边界清晰、体积小 | 已确认公开权利；Apache-2.0 |
| `annotating-math-exam-solutions` | 对应教师讲评和解析版生产，输出结构稳定 | 已确认公开权利；Apache-2.0 |
| `math-docx-to-markdown` | 解决公式密集 Word 转换，附带可执行检查器和测试 | 已确认公开权利；Apache-2.0 |
| `paddleocr-text-recognition` | PaddleOCR 官方维护，成熟且可移植 | Apache-2.0，可公开并保留来源说明 |

## 第二批候选

| 候选 | 暂缓原因 | 后续动作 |
|---|---|---|
| `math-markdown-pdf-polisher` | 含本机绝对路径、运行时路径和多个跨 Skill 依赖 | 拆出便携核心、改成仓库相对路径并跑真实 PDF 回归 |
| `math-rendering-policy` | 引用本机 KaTeX、Node 和 Codex runtime | 改成能力探测和可配置命令，不绑定单机环境 |
| `lecture-pdf-layout` | 模板价值高，但字体和 TeX 环境需要跨平台回退 | 增加字体探测和 A4 小样测试 |
| `word-exam-inline-answers` | 依赖 Word/LibreOffice 兼容策略 | 增加 DOCX fixture 和跨平台验证 |
| `high-school-math-handout-pipeline` | 与试卷主流程部分重叠，路由边界尚需收窄 | 明确讲义与试卷的排他触发条件 |
| `ocr-math-teacher-book-pipeline` | 面向整本教材，范围大于单份试卷工具库 | 作为大型材料扩展包单独治理 |

## 不进入公开工具库

- 绑定个人 WPS、Finder、RemNote、微信会话或聊天交付路径的 Skills。
- 写死私人教材目录、内部题库路径或学校内部资料的 Skills。
- 公众号发布器、通用前端设计、办公套件等与本仓库主链关系较弱的重型包。
- 含二进制缓存、运行日志、测试产物、私有配置或无法确认来源的第三方副本。
