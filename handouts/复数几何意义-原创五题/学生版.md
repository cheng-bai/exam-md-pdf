# 复数的几何意义：五题练习

设 $\mathrm{i}$ 为虚数单位；复数 $z=x+y\mathrm{i}$（$x,y\in\mathbb R$）在复平面内对应的点记为 $Z(x,y)$。

## 1. 旋转与坐标

复数 $z=3+2\mathrm{i}$，令

$$w=\mathrm{i}\bigl(z-(1+\mathrm{i})\bigr)+(1+\mathrm{i}).$$

设复数 $1+\mathrm{i}$、$z$、$w$ 在复平面内对应的点分别为 $C$、$A$、$B$。

（1）求点 $B$ 的坐标。

（2）说明线段 $CA$ 与 $CB$ 的长度关系和位置关系。

## 2. 实轴上的折线最短

设复数 $z$ 为实数。求

$$|z-(1+3\mathrm{i})|+|z-(4+2\mathrm{i})|$$

的最小值，并求取最小值时 $z$ 的值。

## 3. 隐含的圆与模的范围

复数 $z$ 满足

$$|z-1|^2+|z-(3+2\mathrm{i})|^2=12.$$

求 $|z|$ 的取值范围。

## 4. 纯虚数条件下的轨迹

复数 $z\ne3\mathrm{i}$，且

$$\frac{z-1}{z-3\mathrm{i}}$$

是纯虚数。求复数 $z$ 在复平面内对应点的轨迹，并求 $|z|$ 的最小值和最大值。

## 5. 联动变换的轨迹与范围

复数 $z$ 满足 $|z-(2+\mathrm{i})|=1$，令 $w=z+\mathrm{i}\overline z$，其中 $\overline z$ 是 $z$ 的共轭复数。

（1）求 $w$ 在复平面内对应点的轨迹。

（2）求 $|w-(2+2\mathrm{i})|$ 的取值范围。
