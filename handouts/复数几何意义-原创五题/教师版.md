## 1. 旋转与坐标

复数 $z=3+2\mathrm{i}$，令

$$w=\mathrm{i}\bigl(z-(1+\mathrm{i})\bigr)+(1+\mathrm{i}).$$

设复数 $1+\mathrm{i}$、$z$、$w$ 在复平面内对应的点分别为 $C$、$A$、$B$。

（1）求点 $B$ 的坐标。

（2）说明线段 $CA$ 与 $CB$ 的长度关系和位置关系。

**答案：** $B(0,3)$；$CA=CB=\sqrt5$，且 $CA\perp CB$。

**解析：** 因为 $z-(1+\mathrm{i})=2+\mathrm{i}$，所以

$$w=\mathrm{i}(2+\mathrm{i})+1+\mathrm{i}=3\mathrm{i},$$

故 $B(0,3)$。又 $C(1,1)$、$A(3,2)$，从而

$$\overrightarrow{CA}=(2,1),\qquad \overrightarrow{CB}=(-1,2).$$

两向量长度均为 $\sqrt5$，数量积为 $2\times(-1)+1\times2=0$，所以 $CA=CB$ 且 $CA\perp CB$。

进一步看，$w-(1+\mathrm{i})=\mathrm{i}\bigl(z-(1+\mathrm{i})\bigr)$，表示 $\overrightarrow{CB}$ 由 $\overrightarrow{CA}$ 逆时针旋转 $90^\circ$ 得到；本题也可完全通过上述坐标计算验证，不必预先记忆这一结论。

**主要目标与证据：** 能以定点为参照，把复数差转化为向量；正确计算 $w$ 并用向量或旋转关系解释等长、垂直。

## 2. 实轴上的折线最短

设复数 $z$ 为实数。求

$$|z-(1+3\mathrm{i})|+|z-(4+2\mathrm{i})|$$

的最小值，并求取最小值时 $z$ 的值。

**答案：** 最小值为 $\sqrt{34}$，此时 $z=\dfrac{14}{5}$。

**解析：** 设 $z$ 对应点为 $P$，则 $P$ 在实轴上。令 $A(1,3)$、$B(4,2)$，把 $A$ 关于实轴对称得到 $A'(1,-3)$，则 $PA=PA'$。因此

$$PA+PB=PA'+PB\ge A'B=\sqrt{(4-1)^2+(2+3)^2}=\sqrt{34}.$$

由于 $A'$、$B$ 分别位于实轴两侧，线段 $A'B$ 与实轴交于一点；在该点取等号。

设交点为 $P$。由 $A'$ 到 $B$ 的纵坐标从 $-3$ 增至 $2$，交点对应的比例为 $\frac35$，故其横坐标为

$$1+\frac35(4-1)=\frac{14}{5}.$$

所以最小值为 $\sqrt{34}$，且此时 $z=\dfrac{14}{5}$。

**主要目标与证据：** 把两个模解释为到两定点的距离，选择轴对称将折线问题转化为线段最短，并检验等号能取到。

## 3. 隐含的圆与模的范围

复数 $z$ 满足

$$|z-1|^2+|z-(3+2\mathrm{i})|^2=12.$$

求 $|z|$ 的取值范围。

**答案：** $[\sqrt5-2,\sqrt5+2]$。

**解析：** 令 $u=z-(2+\mathrm{i})$。由于 $1$ 与 $3+2\mathrm{i}$ 关于 $2+\mathrm{i}$ 对称，故

$$z-1=u+(1+\mathrm{i}),\qquad z-(3+2\mathrm{i})=u-(1+\mathrm{i}).$$

两式模的平方相加，得到

$$|z-1|^2+|z-(3+2\mathrm{i})|^2=2|u|^2+2|1+\mathrm{i}|^2=2|u|^2+4.$$

由题意，$|z-(2+\mathrm{i})|=2$。所以 $z$ 对应的点 $Z$ 在以 $C(2,1)$ 为圆心、$2$ 为半径的圆上。

原点 $O$ 到圆心的距离为 $OC=\sqrt5>2$。因此

$$\sqrt5-2\le OZ\le\sqrt5+2.$$

两端分别在 $Z$ 位于射线 $OC$ 与圆的近、远交点时取得；$Z$ 沿连接这两点的圆弧连续移动时，$OZ$ 取遍两端之间的所有值。故所求范围为 $[\sqrt5-2,\sqrt5+2]$。

**主要目标与证据：** 利用两定点的中点化简距离平方和，识别圆，再从圆与原点的位置确定范围及取等。

## 4. 纯虚数条件下的轨迹

复数 $z\ne3\mathrm{i}$，且

$$\frac{z-1}{z-3\mathrm{i}}$$

是纯虚数。求复数 $z$ 在复平面内对应点的轨迹，并求 $|z|$ 的最小值和最大值。

**答案：** 轨迹是以 $(1,0)$ 与 $(0,3)$ 为直径两端点的圆，去掉这两个端点；$|z|$ 的最小值为 $0$，最大值为 $\sqrt{10}$。

**解析：** 设 $z=x+y\mathrm{i}$，则 $z\ne3\mathrm{i}$。将分子、分母同乘分母的共轭复数，商的实部为

$$\frac{x(x-1)+y(y-3)}{x^2+(y-3)^2}.$$

商是纯虚数，必须实部为 $0$ 且商不为 $0$。由分母不为 $0$，得

$$x^2+y^2-x-3y=0,\qquad (x,y)\ne(0,3),\ (x,y)\ne(1,0).$$

反过来，满足上述条件时，商的实部为 $0$，且分母、分子均不为 $0$，故商确为纯虚数。配方得

$$\left(x-\frac12\right)^2+\left(y-\frac32\right)^2=\frac52.$$

这就是以 $(1,0)$ 与 $(0,3)$ 为直径两端点的圆，去掉两个端点。

该圆的圆心 $C\left(\frac12,\frac32\right)$ 到原点的距离和半径均为 $\frac{\sqrt{10}}2$。因此圆上点到原点的距离最小为 $0$，最大为 $\sqrt{10}$。这两个极值分别由 $z=0$ 与 $z=1+3\mathrm{i}$ 取得；二者都不在被删去的端点中，满足原条件。

**主要目标与证据：** 根据商为纯虚数建立等价条件，识别圆并排除分母为零和商为零的点，再检查极值取得点。

## 5. 联动变换的轨迹与范围

复数 $z$ 满足 $|z-(2+\mathrm{i})|=1$，令 $w=z+\mathrm{i}\overline z$，其中 $\overline z$ 是 $z$ 的共轭复数。

（1）求 $w$ 在复平面内对应点的轨迹。

（2）求 $|w-(2+2\mathrm{i})|$ 的取值范围。

**答案：**（1）线段 $\{t(1+\mathrm{i})\mid 3-\sqrt2\le t\le3+\sqrt2\}$ 对应的点集。（2）$[0,2+\sqrt2]$。

**解析：** 设 $z=x+y\mathrm{i}$，由题意

$$ (x-2)^2+(y-1)^2=1.$$

又

$$w=(x+y)+(x+y)\mathrm{i}.$$

记 $t=x+y$，则由柯西不等式或平面向量数量积的性质，

$$|t-3|=|(x-2)+(y-1)|\le\sqrt2\sqrt{(x-2)^2+(y-1)^2}=\sqrt2.$$

反过来，对任意 $t\in[3-\sqrt2,3+\sqrt2]$，直线 $x+y=t$ 到圆心 $(2,1)$ 的距离为 $\dfrac{|t-3|}{\sqrt2}\le1$，因此该直线与已知圆有交点，存在相应的 $z$。于是 $t$ 恰好取遍上述闭区间，$w$ 的轨迹是

$$w=t(1+\mathrm{i}),\qquad 3-\sqrt2\le t\le3+\sqrt2,$$

对应的一条线段。

又

$$|w-(2+2\mathrm{i})|=\sqrt2|t-2|.$$

因为 $3-\sqrt2<2<3+\sqrt2$，所以最小值为 $0$；比较两个端点到 $2$ 的距离，最大值为 $\sqrt2(1+\sqrt2)=2+\sqrt2$。由于 $t$ 取遍闭区间，所求范围为 $[0,2+\sqrt2]$。

**主要目标与证据：** 从共轭表达式中保留同一个 $z$ 的联动关系，识别 $w$ 的两个坐标相等，并证明线段上每一点都能取得；再分析距离范围。
