# 复数几何意义原创五题

用途：围绕复数与复平面内的点、向量、距离、简单变换及轨迹组织的一组原创题稿，供专题命题研究、教师备课和分层练习使用。

## 文件

- `教师版.md`：完整题干、答案、解析及主要考查目标。
- `学生版.md`：保留完整题干，不包含答案和解析。
- `题源与命题说明.md`：课程边界、资料线索、设计变化、评分锚点、难度预估和核验记录。

## 交付边界

- 本目录按本次要求采用纯 Markdown 交付，不附 PDF、HTML 或预览图片。
- 五题已经重新计算并做过一次独立复解，教师版与学生版的题干和公式已做一致性检查。
- 复核不等于目标学生实测；难度、用时和区分表现均为命题阶段预估，没有考试数据支持。
- 未做全库、全网查重，题面使用公共数学结构，不保证与已有题目完全无相似。
- 资料中的本机路径已从公开稿移除，只保留来源名称；原文件不随本目录提供。
