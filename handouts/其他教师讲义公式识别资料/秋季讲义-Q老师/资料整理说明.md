## 二、讲次与内容提要（按 PDF 顺序）

### 第一讲 等差数列与等比数列

- **一、等差数列与等比数列的基本性质**
  - 公差、公比；通项公式（以任意第 m 项为首项）；配对原理；等差中项与等比中项。
  - 例题：求项、通项、封闭数列、两等差数列的 max 差数列等。
- **二、等差数列的和数列**
  - 求和公式（三项形式）；S_n/n 为等差数列；S_n 单调性（二次函数视角）。
  - 例题：S_n 与 T_n 比、S_p/q 与 S_q/p、S_n 最值、定值问题、方程根与系数等。
- **三、等比数列的单调性**
  - q=1 / q>1 / 0<q<1 / q<0 的单调性；震荡时的子列单调性。
  - 例题：等差与等比混合、闭区间与公比范围、“伴随数列”等。
- **四、等比数列的和数列**
  - 前 n 项和公式；|q|<1 时的极限与和数列极限。
  - 例题：“M 数列”、“K 数列”、存在性条件、集合最值等。
- **课后练习 1**
  - 等差数列前 n 项和、等差与等比混合判断、S_n/T_n 比、S_n 最值、定值、公差/公比范围、“相伴数列”等综合题。
