# 公开发布检查清单

## 内容边界

- [ ] 已确认试卷、讲义、图片和 PDF 的公开授权范围。
- [ ] 没有学生隐私、私人聊天、内部学校资料或账号信息。
- [ ] 没有 API token、cookie、密码、二维码或本机配置。

## 文件边界

- [ ] 最终目录只包含语义化命名的 Markdown、PDF 和必要题图。
- [ ] 没有 `result.zip`、`summary.json`、`full.md`、`source.md`、`student.md`、`QUALITY_REPORT.md`。
- [ ] 没有原始扫描 PDF、页面预览、OCR dump 或上传回执。
- [ ] Markdown 不包含 Windows 或 macOS 本机绝对路径。

## 可用性

- [ ] 同名 `.md/.pdf` 存在。
- [ ] PDF 可打开、页数合理且为 A4。
- [ ] Markdown 图片引用存在并已跟踪。
- [ ] 相关脚本和测试通过。

## Git

- [ ] 已确认仓库 visibility 与本批内容授权一致。
- [ ] 暂存区只包含本次目标目录和必要依赖。
- [ ] 提交标题和正文使用中文说明任务与验证结果。
- [ ] 推送前再次查看 `git diff --cached --name-status`。
