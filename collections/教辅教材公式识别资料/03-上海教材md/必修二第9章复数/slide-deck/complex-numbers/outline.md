## 幻灯片结构

### 第1页：封面
- **标题**: 第9章 复数
- **副标题**: 从代数到几何的桥梁
- **视觉**: 复平面背景，简洁数学美感

### 第2页：章节导航
- **内容**: 9.1 复数及其四则运算 | 9.2 复数的几何意义
- **视觉**: 两栏布局，图标引导

### 第3页：引入 — 负数开平方的问题
- **内容**: 实系数一元二次方程不总有实数解
- **历史**: 16世纪数学家引入"虚数"
- **视觉**: 问题提出，历史背景

### 第4页：虚数单位的定义
- **内容**: 虚数单位 i，规定 i² = -1
- **推导**: (bi)² = -b²，负数开平方的解决
- **视觉**: 核心定义高亮，公式展示

### 第5页：复数的定义
- **内容**: 形如 a + bi（a、b∈R）的数称为复数
- **集合**: 全体复数构成集合 C
- **约定**: 相等条件、零的条件
- **视觉**: 定义框，集合图示

### 第6页：四则运算 — 加减法
- **内容**: (a+bi) ± (c+di) = (a±c) + (b±d)i
- **方法**: 按多项式加减，合并同类项
- **视觉**: 公式推导，步骤清晰

### 第7页：四则运算 — 乘法
- **内容**: (a+bi)(c+di) = (ac-bd) + (bc+ad)i
- **方法**: 多项式相乘，i² = -1 化简
- **视觉**: 推导过程，关键步骤高亮

### 第8页：四则运算 — 除法
- **内容**: 分母实数化，乘以共轭复数
- **公式**: (a+bi)/(c+di) = [(ac+bd)+(bc-ad)i]/(c²+d²)
- **视觉**: 推导过程，类比"分母有理化"

### 第9页：例题1 — 计算示范
- **内容**: 四道计算题示范
- **重点**: 加减乘除综合运用
- **视觉**: 左题右解，步骤清晰

### 第10页：实部、虚部与共轭复数
- **内容**: Re z = a, Im z = b, z̄ = a - bi
- **分类**: 实数、虚数、纯虚数
- **视觉**: 分类树状图，颜色区分

### 第11页：共轭复数的性质
- **内容**: 性质(1) z̄̄ = z；性质(2) 与四则运算可交换
- **证明**: 乘法与除法的验证
- **视觉**: 性质列表，证明推导

### 第12页：例题2 — 综合应用
- **内容**: 求实数m的值或范围
- **类型**: 实数、虚数、纯虚数、零
- **视觉**: 分类讨论，表格展示

### 第13页：9.2 引入 — 复数的几何意义
- **内容**: 从代数到几何的桥梁
- **对应**: 复数 ↔ 有序实数对 ↔ 平面上的点
- **视觉**: 映射关系图

### 第14页：复平面
- **内容**: 复平面的定义，实轴、虚轴
- **图示**: x轴=实轴(Re)，y轴=虚轴(Im)
- **视觉**: 复平面大图，标注清晰

### 第15页：复数的向量表示
- **内容**: 复数 z = a+bi 对应向量 OZ = (a,b)
- **运算**: 复数加法 = 向量加法（平行四边形法则）
- **视觉**: 向量图示，平行四边形

### 第16页：例题3 — 几何应用
- **内容**: 平行四边形顶点问题
- **方法**: z_B = z_A + z_C
- **视觉**: 几何图形，标注复数

### 第17页：章节总结
- **内容**:
  - 复数的代数形式 a+bi
  - 四则运算规则
  - 共轭复数及其性质
  - 复平面与向量表示
- **视觉**: 4个要点卡片，图标+总结

### 第18页：结束页
- **内容**: 思考与练习
- **视觉**: 简洁，鼓励探索
