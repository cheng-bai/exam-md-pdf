# 第3章 空间向量及其应用 - 完整讲义

## 一、本章解决什么问题

本章将在空间中讨论向量，核心问题是：**如何用代数方法解决立体几何问题？**

### 本章学习目标
1. **理解空间向量与平面向量的联系与区别**：空间向量是平面向量在三维空间的自然推广
2. **掌握空间向量的运算规则**：加法、减法、数乘、数量积
3. **建立空间直角坐标系**：将几何问题转化为代数计算
4. **应用空间向量解决立体几何问题**：包括判断位置关系、求距离、求角度等

### 核心思想方法
- **数形结合**：用向量的代数运算解决几何问题
- **转化思想**：将空间问题转化为平面问题处理
- **坐标化**：建立坐标系，将几何条件转化为坐标运算

## 三、核心知识点详解

### 3.1 空间向量及其运算

#### 1. 共面向量的概念
**定义**：如果一组向量可以平移到同一个平面上，那么称这组向量是**共面的**。

**重要结论**：
- 任意两个向量总是共面的
- 空间中三个向量不一定共面

#### 2. 空间向量的运算规则
空间向量的加法、减法、数乘、数量积的定义与平面向量完全相同。

**加法结合律的证明**：
对于任意三个向量 $\overrightarrow{AB}, \overrightarrow{BC}, \overrightarrow{CD}$：
$$(\overrightarrow{AB} + \overrightarrow{BC}) + \overrightarrow{CD} = \overrightarrow{AC} + \overrightarrow{CD} = \overrightarrow{AD}$$
$$\overrightarrow{AB} + (\overrightarrow{BC} + \overrightarrow{CD}) = \overrightarrow{AB} + \overrightarrow{BD} = \overrightarrow{AD}$$

**首尾规则**：若干个起点、终点依次相接的向量的和是以第一个向量的起点为起点，以最后一个向量的终点为终点的向量。

#### 3. 数量积运算
$$\overrightarrow{a} \cdot \overrightarrow{b} = |\overrightarrow{a}| |\overrightarrow{b}| \cos\langle \overrightarrow{a}, \overrightarrow{b} \rangle$$

**分配律**：$\overrightarrow{a} \cdot (\overrightarrow{b} + \overrightarrow{c}) = \overrightarrow{a} \cdot \overrightarrow{b} + \overrightarrow{a} \cdot \overrightarrow{c}$

**垂直条件**：$\overrightarrow{a} \perp \overrightarrow{b} \Leftrightarrow \overrightarrow{a} \cdot \overrightarrow{b} = 0$

**平行条件**：$\overrightarrow{a} // \overrightarrow{b} \Leftrightarrow \overrightarrow{b} = \lambda \overrightarrow{a}$（$\lambda \in \mathbb{R}$）

---

### 3.2 空间向量基本定理

#### 1. 向量共面的充要条件
**定理**：如果 $\overrightarrow{e_1}$ 与 $\overrightarrow{e_2}$ 是两个不平行的向量，那么空间中的向量 $\overrightarrow{a}$ 与 $\overrightarrow{e_1}, \overrightarrow{e_2}$ 共面的充要条件是：存在唯一的一对实数 $\lambda$ 与 $\mu$，使得
$$\overrightarrow{a} = \lambda \overrightarrow{e_1} + \mu \overrightarrow{e_2}$$

#### 2. 空间向量基本定理
**定理**：如果 $\overrightarrow{e_1}, \overrightarrow{e_2}, \overrightarrow{e_3}$ 是不共面的向量，那么对空间中任意一个向量 $\overrightarrow{a}$，存在唯一的一组实数 $\lambda, \mu, \nu$，使得
$$\overrightarrow{a} = \lambda \overrightarrow{e_1} + \mu \overrightarrow{e_2} + \nu \overrightarrow{e_3}$$

**说明**：
- $\{\overrightarrow{e_1}, \overrightarrow{e_2}, \overrightarrow{e_3}\}$ 称为空间的一组**基底**
- 当基底为单位正交基底时，$(\lambda, \mu, \nu)$ 就是向量的坐标

---

### 3.3 空间向量的坐标表示

#### 1. 空间直角坐标系
- 从空间一点 $O$ 出发，作三条两两互相垂直的坐标轴：$x$轴、$y$轴、$z$轴
- 采用**右手系**：右手四指从 $x$ 轴正方向转向 $y$ 轴正方向，拇指指向 $z$ 轴正方向
- 三个坐标平面：$xOy$ 平面、$yOz$ 平面、$zOx$ 平面

#### 2. 向量的坐标表示
设 $\overrightarrow{i}, \overrightarrow{j}, \overrightarrow{k}$ 分别是 $x, y, z$ 轴正方向的单位向量，则：
$$\overrightarrow{p} = (x, y, z) = x\overrightarrow{i} + y\overrightarrow{j} + z\overrightarrow{k}$$

#### 3. 坐标运算公式
设 $\overrightarrow{a} = (x_1, y_1, z_1)$，$\overrightarrow{b} = (x_2, y_2, z_2)$：

| 运算 | 公式 |
|------|------|
| 加法 | $\overrightarrow{a} + \overrightarrow{b} = (x_1+x_2, y_1+y_2, z_1+z_2)$ |
| 减法 | $\overrightarrow{a} - \overrightarrow{b} = (x_1-x_2, y_1-y_2, z_1-z_2)$ |
| 数乘 | $\lambda \overrightarrow{a} = (\lambda x_1, \lambda y_1, \lambda z_1)$ |
| 数量积 | $\overrightarrow{a} \cdot \overrightarrow{b} = x_1x_2 + y_1y_2 + z_1z_2$ |
| 模 | $|\overrightarrow{a}| = \sqrt{x_1^2 + y_1^2 + z_1^2}$ |

#### 4. 两点间距离公式
设 $P(x_1, y_1, z_1)$，$Q(x_2, y_2, z_2)$，则：
$$|PQ| = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2 + (z_2-z_1)^2}$$

#### 5. 夹角公式
$$\cos\langle \overrightarrow{a}, \overrightarrow{b} \rangle = \frac{x_1x_2 + y_1y_2 + z_1z_2}{\sqrt{x_1^2+y_1^2+z_1^2} \cdot \sqrt{x_2^2+y_2^2+z_2^2}}$$

**垂直条件**：$\overrightarrow{a} \perp \overrightarrow{b} \Leftrightarrow x_1x_2 + y_1y_2 + z_1z_2 = 0$

**平行条件**：$\overrightarrow{a} // \overrightarrow{b} \Leftrightarrow \frac{x_1}{x_2} = \frac{y_1}{y_2} = \frac{z_1}{z_2}$（分母不为零）

---

### 3.4 空间向量在立体几何中的应用

#### 1. 方向向量与法向量
- **直线的方向向量**：与直线平行的任何非零向量
- **平面的法向量**：垂直于平面的任何非零向量

#### 2. 位置关系的向量判定

| 位置关系 | 向量条件 |
|----------|----------|
| 线线平行 | 方向向量平行：$\overrightarrow{r_1} // \overrightarrow{r_2}$ |
| 线线垂直 | 方向向量垂直：$\overrightarrow{r_1} \cdot \overrightarrow{r_2} = 0$ |
| 线面平行 | 方向向量⊥法向量：$\overrightarrow{r} \cdot \overrightarrow{n} = 0$ |
| 线面垂直 | 方向向量//法向量：$\overrightarrow{r} // \overrightarrow{n}$ |
| 面面平行 | 法向量平行：$\overrightarrow{n_1} // \overrightarrow{n_2}$ |
| 面面垂直 | 法向量垂直：$\overrightarrow{n_1} \cdot \overrightarrow{n_2} = 0$ |

#### 3. 距离公式

**点到平面的距离**：
$$d = \frac{|\overrightarrow{n} \cdot \overrightarrow{AB}|}{|\overrightarrow{n}|}$$
其中 $\overrightarrow{n}$ 是平面的法向量，$B$ 是平面上任意一点。

**平行线到平面的距离**：转化为平行线上一点到平面的距离

**平行平面间的距离**：转化为一个平面上一点到另一个平面的距离

#### 4. 角度公式

**异面直线所成角**：
$$\cos\theta = \frac{|\overrightarrow{r_1} \cdot \overrightarrow{r_2}|}{|\overrightarrow{r_1}| |\overrightarrow{r_2}|}$$

**直线与平面所成角**：
$$\sin\theta = \frac{|\overrightarrow{r} \cdot \overrightarrow{n}|}{|\overrightarrow{r}| |\overrightarrow{n}|}$$

**二面角**：
$$\cos\theta = \frac{|\overrightarrow{n_1} \cdot \overrightarrow{n_2}|}{|\overrightarrow{n_1}| |\overrightarrow{n_2}|}$$

## 四、典型例题精讲

### 例题1：空间向量的线性表示
**题目**：在正方体 $ABCD-A_1B_1C_1D_1$ 中，设 $\overrightarrow{AA_1} = \overrightarrow{a}$，$\overrightarrow{AB} = \overrightarrow{b}$，$\overrightarrow{AD} = \overrightarrow{c}$，试用 $\overrightarrow{a}, \overrightarrow{b}, \overrightarrow{c}$ 的线性组合表示向量 $\overrightarrow{AC_1}$。

**解析**：
$$\overrightarrow{AC_1} = \overrightarrow{AB} + \overrightarrow{BC} + \overrightarrow{CC_1} = \overrightarrow{AB} + \overrightarrow{AD} + \overrightarrow{AA_1} = \overrightarrow{b} + \overrightarrow{c} + \overrightarrow{a}$$

**答案**：$\overrightarrow{AC_1} = \overrightarrow{a} + \overrightarrow{b} + \overrightarrow{c}$

---

### 例题2：向量共面性判断
**题目**：在平行六面体 $ABCD-A_1B_1C_1D_1$ 中，$E$ 是棱 $AA_1$ 的中点，$O$ 是面对角线 $BC_1$ 与 $B_1C$ 的交点。判断向量 $\overrightarrow{EO}$ 与 $\overrightarrow{AB}, \overrightarrow{AD}$ 是否共面。

**解析**：
$$\overrightarrow{EO} = \overrightarrow{EA} + \overrightarrow{AB} + \overrightarrow{BO} = -\frac{1}{2}\overrightarrow{AA_1} + \overrightarrow{AB} + \frac{1}{2}(\overrightarrow{AD} + \overrightarrow{AA_1}) = \overrightarrow{AB} + \frac{1}{2}\overrightarrow{AD}$$

**结论**：$\overrightarrow{EO} = \overrightarrow{AB} + \frac{1}{2}\overrightarrow{AD}$，所以 $\overrightarrow{EO}$ 与 $\overrightarrow{AB}, \overrightarrow{AD}$ 共面。

---

### 例题3：空间向量的数量积计算
**题目**：在正方体 $ABCD-A_1B_1C_1D_1$ 中，棱长为 $a$，$E$ 是棱 $CC_1$ 的中点。
(1) 求 $\overrightarrow{DD_1} \cdot \overrightarrow{DC_1}$
(2) 求 $\overrightarrow{AE}$ 与 $\overrightarrow{C_1A_1}$ 的夹角

**解析**：

(1) 由 $\overrightarrow{DD_1} \perp \overrightarrow{D_1C_1}$，$|\overrightarrow{DD_1}| = |\overrightarrow{D_1C_1}| = a$，得 $|\overrightarrow{DC_1}| = \sqrt{2}a$

$$\overrightarrow{DD_1} \cdot \overrightarrow{DC_1} = |\overrightarrow{DD_1}| |\overrightarrow{DC_1}| \cos 45° = a \cdot \sqrt{2}a \cdot \frac{\sqrt{2}}{2} = a^2$$

(2) $\overrightarrow{AE} = \overrightarrow{AB} + \overrightarrow{BC} + \frac{1}{2}\overrightarrow{AA_1}$，$\overrightarrow{C_1A_1} = -\overrightarrow{AB} - \overrightarrow{BC}$

$$\overrightarrow{AE} \cdot \overrightarrow{C_1A_1} = -|\overrightarrow{AB}|^2 - |\overrightarrow{BC}|^2 = -2a^2$$

$$|\overrightarrow{AE}| = \frac{3a}{2}, \quad |\overrightarrow{C_1A_1}| = \sqrt{2}a$$

$$\cos\theta = \frac{-2a^2}{\frac{3a}{2} \cdot \sqrt{2}a} = -\frac{2\sqrt{2}}{3}$$

**答案**：(1) $a^2$；(2) $\pi - \arccos\frac{2\sqrt{2}}{3}$

---

### 例题4：建立坐标系求夹角
**题目**：在正方体 $ABCD-A_1B_1C_1D_1$ 中，求对角线 $CA_1$ 与 $CA$ 所成角的余弦值。

**解析**：
以 $A$ 为原点，$\overrightarrow{AB}, \overrightarrow{AD}, \overrightarrow{AA_1}$ 方向为 $x, y, z$ 轴正方向，设棱长为 $a$。

则 $C(a, a, 0)$，$A_1(0, 0, a)$，$A(0, 0, 0)$

$$\overrightarrow{CA_1} = (-a, -a, a), \quad \overrightarrow{CA} = (-a, -a, 0)$$

$$\overrightarrow{CA_1} \cdot \overrightarrow{CA} = a^2 + a^2 = 2a^2$$

$$|\overrightarrow{CA_1}| = \sqrt{3}a, \quad |\overrightarrow{CA}| = \sqrt{2}a$$

$$\cos\theta = \frac{2a^2}{\sqrt{3}a \cdot \sqrt{2}a} = \frac{\sqrt{6}}{3}$$

**答案**：$\frac{\sqrt{6}}{3}$

---

### 例题5：证明线面垂直
**题目**：在正方体 $ABCD-A_1B_1C_1D_1$ 中，求证：$AC_1 \perp$ 平面 $A_1BD$。

**解析**：
以 $D$ 为原点建立坐标系，设棱长为 $a$。

各点坐标：$A(a, 0, 0)$，$B(a, a, 0)$，$D(0, 0, 0)$，$A_1(a, 0, a)$，$C_1(0, a, a)$

$$\overrightarrow{AC_1} = (-a, a, a)$$
$$\overrightarrow{A_1B} = (0, a, -a), \quad \overrightarrow{A_1D} = (-a, 0, -a)$$

$$\overrightarrow{AC_1} \cdot \overrightarrow{A_1B} = 0 + a^2 - a^2 = 0$$
$$\overrightarrow{AC_1} \cdot \overrightarrow{A_1D} = a^2 + 0 - a^2 = 0$$

所以 $AC_1 \perp A_1B$，$AC_1 \perp A_1D$，故 $AC_1 \perp$ 平面 $A_1BD$。

---

### 例题6：求点到平面的距离
**题目**：在长方体 $ABCD-A'B'C'D'$ 中，$|AB| = 2$，$|AD| = |AA'| = 1$。求顶点 $B'$ 到平面 $D'AC$ 的距离。

**解析**：
以 $D'$ 为原点建立坐标系：$D'(0, 0, 0)$，$A(1, 0, 1)$，$C(0, 2, 1)$，$B'(1, 2, 0)$

$$\overrightarrow{D'A} = (1, 0, 1), \quad \overrightarrow{D'C} = (0, 2, 1)$$

设平面 $D'AC$ 的法向量 $\overrightarrow{n} = (u, v, w)$：
$$\begin{cases} u + w = 0 \\ 2v + w = 0 \end{cases}$$

取 $v = 1$，则 $w = -2$，$u = 2$，所以 $\overrightarrow{n} = (2, 1, -2)$

$$\overrightarrow{B'C} = (-1, 0, 1)$$

$$d = \frac{|\overrightarrow{n} \cdot \overrightarrow{B'C}|}{|\overrightarrow{n}|} = \frac{|-2 + 0 - 2|}{\sqrt{4+1+4}} = \frac{4}{3}$$

**答案**：$\frac{4}{3}$

---

### 例题7：求异面直线所成角
**题目**：在正方体 $ABCD-A_1B_1C_1D_1$ 中，$E, F$ 分别是 $AD, AB$ 的中点。求直线 $B'E$ 与 $C'F$ 所成角的大小。

**解析**：
以 $D'$ 为原点，设棱长为 $a$。

$B'(a, a, 0)$，$E(\frac{a}{2}, 0, a)$，$C'(0, a, 0)$，$F(a, \frac{a}{2}, a)$

$$\overrightarrow{B'E} = (-\frac{a}{2}, -a, a), \quad \overrightarrow{C'F} = (a, -\frac{a}{2}, a)$$

$$\overrightarrow{B'E} \cdot \overrightarrow{C'F} = -\frac{a^2}{2} + \frac{a^2}{2} + a^2 = a^2$$

$$|\overrightarrow{B'E}| = |\overrightarrow{C'F}| = \frac{3a}{2}$$

$$\cos\theta = \frac{a^2}{\frac{9a^2}{4}} = \frac{4}{9}$$

**答案**：$\arccos\frac{4}{9}$

---

### 例题8：求二面角
**题目**：在正四棱锥 $P-ABCD$ 中，$|PA| = |AB| = 2\sqrt{2}$，$E, F$ 分别为 $PB, PD$ 的中点。求平面 $AEF$ 与平面 $ABCD$ 所成二面角的大小。

**解析**：
以底面中心 $O$ 为原点，$OA, OB, OP$ 方向为 $x, y, z$ 轴。

由条件得 $|OA| = |OB| = |OP| = 2$

$A(2, 0, 0)$，$E(0, 1, 1)$，$F(0, -1, 1)$

$$\overrightarrow{AE} = (-2, 1, 1), \quad \overrightarrow{AF} = (-2, -1, 1)$$

设平面 $AEF$ 的法向量 $\overrightarrow{n} = (u, v, w)$：
$$\begin{cases} -2u + v + w = 0 \\ -2u - v + w = 0 \end{cases}$$

取 $u = 1$，则 $v = 0$，$w = 2$，所以 $\overrightarrow{n} = (1, 0, 2)$

平面 $ABCD$ 的法向量 $\overrightarrow{m} = (0, 0, 1)$

$$\cos\theta = \frac{|\overrightarrow{m} \cdot \overrightarrow{n}|}{|\overrightarrow{m}| |\overrightarrow{n}|} = \frac{2}{\sqrt{5}} = \frac{2\sqrt{5}}{5}$$

**答案**：$\arccos\frac{2\sqrt{5}}{5}$（锐二面角）

## 五、方法技巧总结

### 1. 建系技巧

**选择合适的原点**：
- 优先选择几何体的顶点或对称中心
- 使尽可能多的点落在坐标轴上
- 使坐标值尽量简单（多为0或1）

**常见几何体的建系方法**：

| 几何体 | 建系方法 |
|--------|----------|
| 正方体/长方体 | 以一个顶点为原点，三条棱为坐标轴 |
| 正棱锥 | 以底面中心为原点，高为z轴 |
| 直棱柱 | 以底面顶点为原点，侧棱为z轴 |

### 2. 法向量求法

**方法一：待定系数法**
1. 设 $\overrightarrow{n} = (x, y, z)$
2. 利用 $\overrightarrow{n}$ 与平面内两个不共线向量垂直列方程
3. 给一个变量赋值，解出其他变量

**方法二：叉积法（了解）**
若 $\overrightarrow{a}, \overrightarrow{b}$ 是平面内两个不共线向量，则 $\overrightarrow{n} = \overrightarrow{a} \times \overrightarrow{b}$ 是平面的法向量。

### 3. 角度问题转化

```
几何问题          向量问题          计算公式
─────────        ─────────        ─────────
线线夹角    →   方向向量夹角   →   cosθ = |r₁·r₂|/(|r₁||r₂|)
线面夹角    →   方向向量与法向量  →  sinθ = |r·n|/(|r||n|)
二面角      →   法向量夹角      →   cosθ = |n₁·n₂|/(|n₁||n₂|)
```

### 4. 距离问题转化

```
点面距离 = |n·AB|/|n|    （B为平面上任意一点）
线面距离 = 点面距离       （线上任取一点）
面面距离 = 点面距离       （一个平面上任取一点）
```

## 六、易错点警示

### 易错点1：混淆向量的夹角与几何角

**错误**：直接用向量夹角公式求出的角就是几何角

**纠正**：
- 异面直线所成角 $\in [0, \frac{\pi}{2}]$，取方向向量夹角的锐角
- 线面角 $\in [0, \frac{\pi}{2}]$，注意 $\sin\theta = |\cos\langle \overrightarrow{r}, \overrightarrow{n} \rangle|$
- 二面角 $\in [0, \pi]$，需要根据图形判断是锐角还是钝角

### 易错点2：法向量方向判断错误

**错误**：认为法向量夹角就是二面角

**纠正**：
- 法向量夹角与二面角相等或互补
- 需要根据图形判断二面角是锐角还是钝角
- 也可通过观察两个法向量的指向来确定

### 易错点3：坐标计算错误

**常见错误**：
- 向量坐标 = 终点坐标 - 起点坐标，顺序不能颠倒
- 数量积是标量，不是向量
- 求模时别忘了开平方

### 易错点4：建系不当

**错误**：随意建立坐标系，导致计算复杂

**纠正**：
- 充分利用几何体的对称性
- 使关键点坐标尽量简单
- 尽量让坐标轴与几何体的棱或高重合

### 易错点5：忽略共面条件

**错误**：直接用平面向量方法处理空间问题

**纠正**：
- 三个向量不一定共面，不能随意用平面向量基本定理
- 必须验证共面条件后才能用线性组合表示

## 七、分层练习设计

### A组 基础巩固

**练习1**：在正方体 $ABCD-A_1B_1C_1D_1$ 中，化简下列向量表达式：
(1) $\overrightarrow{AB} + \overrightarrow{BC} + \overrightarrow{CC_1}$
(2) $\overrightarrow{AB} - \overrightarrow{AD} + \overrightarrow{DD_1}$

**练习2**：已知 $\overrightarrow{a} = (1, 2, 3)$，$\overrightarrow{b} = (2, -1, 1)$，求：

(2) $\overrightarrow{a} \cdot \overrightarrow{b}$
(3) $\overrightarrow{a}$ 与 $\overrightarrow{b}$ 夹角的余弦值

**练习3**：在空间直角坐标系中，$A(1, 2, 3)$，$B(3, -1, 2)$，求：
(1) 向量 $\overrightarrow{AB}$ 的坐标
(2) $|\overrightarrow{AB}|$
(3) $\overrightarrow{AB}$ 的单位向量

### B组 能力提升

**练习4**：在正方体 $ABCD-A_1B_1C_1D_1$ 中，棱长为2，$E$ 为 $CC_1$ 中点。建立适当坐标系，求：
(1) 平面 $A_1BD$ 的法向量
(2) 点 $E$ 到平面 $A_1BD$ 的距离

**练习5**：在直三棱柱 $ABC-A_1B_1C_1$ 中，$\angle ACB = 90°$，$|CA| = |CB| = |CC_1| = 2$，$M, N$ 分别是 $A_1B_1, A_1A$ 的中点。建立坐标系求：
(1) $BN$ 的模
(2) $\cos\langle \overrightarrow{BA_1}, \overrightarrow{CB_1} \rangle$
(3) 证明：$A_1B \perp C_1M$

**练习6**：在四棱锥 $P-ABCD$ 中，$PA \perp$ 平面 $ABCD$，$AB \perp AD$，$BC // AD$，$|PA| = |AB| = |BC| = 1$，$|CD| = \sqrt{2}$，$\angle CDA = 45°$。求直线 $PB$ 与平面 $PCD$ 所成角的大小。

### C组 拓展探究

**练习7**：在正方体 $ABCD-A_1B_1C_1D_1$ 中，动点 $P$ 在对角线 $BD_1$ 上，记 $\frac{|D_1P|}{|D_1B|} = \lambda$。
(1) 求证：$AP \perp B_1C$
(2) 若异面直线 $AP$ 与 $D_1B_1$ 所成角为 $\frac{\pi}{4}$，求 $\lambda$ 的值

**练习8**：在正四棱柱 $ABCD-A_1B_1C_1D_1$ 中，$|AA_1| = 2|AB| = 2$，$E$ 为 $AA_1$ 的中点。
(1) 求异面直线 $BE$ 与 $CD_1$ 所成角的大小

## 附录：公式速查表

### 1. 向量运算公式

| 运算 | 公式 |
|------|------|
| 加法 | $\overrightarrow{a} + \overrightarrow{b} = (x_1+x_2, y_1+y_2, z_1+z_2)$ |
| 减法 | $\overrightarrow{a} - \overrightarrow{b} = (x_1-x_2, y_1-y_2, z_1-z_2)$ |
| 数乘 | $\lambda\overrightarrow{a} = (\lambda x_1, \lambda y_1, \lambda z_1)$ |
| 数量积 | $\overrightarrow{a} \cdot \overrightarrow{b} = x_1x_2 + y_1y_2 + z_1z_2$ |
| 模 | $|\overrightarrow{a}| = \sqrt{x_1^2 + y_1^2 + z_1^2}$ |

### 2. 位置关系判定

| 关系 | 向量条件 |
|------|----------|
| 线线平行 | $\overrightarrow{r_1} // \overrightarrow{r_2}$ |
| 线线垂直 | $\overrightarrow{r_1} \cdot \overrightarrow{r_2} = 0$ |
| 线面平行 | $\overrightarrow{r} \cdot \overrightarrow{n} = 0$ |
| 线面垂直 | $\overrightarrow{r} // \overrightarrow{n}$ |
| 面面平行 | $\overrightarrow{n_1} // \overrightarrow{n_2}$ |
| 面面垂直 | $\overrightarrow{n_1} \cdot \overrightarrow{n_2} = 0$ |

### 3. 度量公式

| 度量 | 公式 |
|------|------|
| 两点距离 | $d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2 + (z_2-z_1)^2}$ |
| 点面距离 | $d = \frac{|\overrightarrow{n} \cdot \overrightarrow{AB}|}{|\overrightarrow{n}|}$ |
| 异面直线角 | $\cos\theta = \frac{|\overrightarrow{r_1} \cdot \overrightarrow{r_2}|}{|\overrightarrow{r_1}| |\overrightarrow{r_2}|}$ |
| 线面角 | $\sin\theta = \frac{|\overrightarrow{r} \cdot \overrightarrow{n}|}{|\overrightarrow{r}| |\overrightarrow{n}|}$ |
| 二面角 | $\cos\theta = \frac{|\overrightarrow{n_1} \cdot \overrightarrow{n_2}|}{|\overrightarrow{n_1}| |\overrightarrow{n_2}|}$ |
