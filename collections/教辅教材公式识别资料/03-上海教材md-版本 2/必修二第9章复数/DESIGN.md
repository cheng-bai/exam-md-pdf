# 数学教学演示设计指南 - 复数章节

## 概述

本设计指南专为**高中数学复数章节教学演示**定制，适用于 PowerPoint、Keynote 或 PDF 格式的教学幻灯片。设计风格追求**清晰、专业、数学美感**，帮助学生理解复数的概念、运算和几何意义。

## 设计理念

- **清晰优先**：数学公式和概念必须清晰可读
- **几何直观**：复数与几何的关联需要可视化呈现
- **层次分明**：定义、定理、例题、练习层级分明
- **色彩克制**：避免花哨，用色彩区分数学元素

## 色彩系统

### 主色调
- **背景色**：`#FFFFFF`（纯白）或 `#F8F9FA`（微灰白）
- **主文字**：`#1A1A2E`（深蓝黑）
- **次要文字**：`#4A4A6A`（中灰蓝）

### 数学元素色彩
- **实数/实部**：`#2E7D32`（绿色）
- **虚数/虚部**：`#C62828`（红色）
- **复数整体**：`#1565C0`（蓝色）
- **强调/重点**：`#F57C00`（橙色）
- **几何图形**：`#6A1B9A`（紫色）

### 辅助色
- **边框/分隔线**：`#E0E0E0`（浅灰）
- **例题背景**：`#E3F2FD`（淡蓝）
- **练习背景**：`#FFF3E0`（淡橙）
- **定理背景**：`#F3E5F5`（淡紫）

## 布局规范

### 标准页面结构
```
+------------------------------------------+
|  页眉（章节标题，12%高度）                  |
+------------------------------------------+
|                                          |
|  主内容区（76%高度）                       |
|  - 定义/定理框                            |
|  - 公式展示                               |
|  - 例题解析                               |
|  - 几何图示                               |
|                                          |
+------------------------------------------+
|  页脚（页码/备注，12%高度）                |
+------------------------------------------+
```

### 特殊页面类型

**1. 概念引入页**
- 左侧：问题/历史背景（40%）
- 右侧：核心定义（60%）
- 底部：关键公式高亮

**2. 公式推导页**
- 顶部：当前步骤说明
- 中部：分步公式（每步单独一行）
- 底部：结论框

**3. 例题解析页**
- 左侧：题目（30%）
- 右侧：解答过程（70%）
- 关键步骤用橙色标记

**4. 几何图示页**
- 中央：复平面图示（60%）
- 右侧：标注说明（40%）
- 实轴绿色，虚轴红色

**5. 总结页**
- 网格布局：4-6个要点卡片
- 每个卡片：图标 + 标题 + 一句话说明

## 数学元素样式

### 复数表示规范
- 标准形式：`z = a + bi`
  - `a` 用绿色表示（实部）
  - `b` 用红色表示（虚部系数）
  - `i` 用蓝色斜体表示（虚数单位）
- 共轭复数：`z̄ = a - bi`（上方加横线）
- 复平面点：`Z(a, b)`

### 公式展示规则
1. **单行公式**：居中，字号18pt，上下留白16pt
2. **多行推导**：左对齐，等号对齐，每行编号
3. **关键步骤**：用橙色高亮框标记
4. **条件说明**：公式下方用小字标注（12pt，灰色）

### 几何图示规范
- **复平面**：
  - 实轴（x轴）：绿色，标注 "Re"
  - 虚轴（y轴）：红色，标注 "Im"
  - 原点：黑色圆点
  - 单位长度：统一比例
- **向量表示**：
  - 从原点出发的箭头
  - 终点标注复数 `z = a + bi`
  - 向量用蓝色

## 动画与过渡

### 推荐动画
- **公式推导**：逐行出现（Fade In + 0.3s延迟）
- **几何图示**：元素依次绘制（Wipe效果）
- **重点标记**：脉冲高亮（Pulse，持续2秒）

### 过渡效果
- 章节间：Push（推进感）
- 页面间：Fade（简洁）
- 避免：花哨的3D翻转、溶解效果

2. **定义页**：复平面的概念

## 输出规格

- **分辨率**：1920×1080（16:9）
- **格式**：PNG（单页）或 PDF（整份）
- **色彩模式**：RGB
- **DPI**：150（屏幕展示）/ 300（打印）

## 使用建议

1. **每页聚焦一个概念**：避免信息过载
2. **公式逐步展示**：不要一次性呈现所有推导
3. **多用图示**：复数的几何意义是理解关键
4. **留白充足**：数学内容需要呼吸空间
5. **一致性**：同一章节保持风格统一
