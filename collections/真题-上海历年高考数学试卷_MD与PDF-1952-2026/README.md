# 上海历年高考数学试卷交付包

## 内容

- `01_上海试卷_Markdown/`：97 份可独立搬运的 Markdown 试卷，每卷自带 `images/`。
- `02_答案解析版_按年份/`：原 7062 页答案解析版按 64 个年份拆分，另保留原书第 1–13 页目录。
- `03_上海全部试卷_答案解析合集.pdf`：所有上海卷的答案解析总合集。
- `04_上海合集_按年份/`：上海卷按 43 个年份拆分。
- `上海试卷清单.csv`：试卷名称、年份、来源与 Markdown 路径。
- `manifest.json`：机器可读的页码范围、文件路径和验证结果。

## 验证摘要

- Markdown：97 份。
- 复制图片：390 张。
- PDF：109 份。
- Markdown/图片引用错误：0 项。
