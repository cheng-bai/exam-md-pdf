# 数学试卷答案与考点标注

## 概览

把数学试卷 Markdown 整理成便于讲评的注释版。简单题轻标注，中难题突出诊断价值；每题答案和解析必须紧跟题目。

## 输出结构

保留原试卷顺序和元信息。在考试信息之后、第一道题之前插入：

```markdown
## 本卷考点结构总览

> 使用说明：基础题只保留最小必要考点；中难题突出“核心考点”和“学生易卡点”。题后标签与本总览对应，便于讲评、错题归因和一对一补弱。

### 一、一级模块

#### 1.1 二级考点
- 涉及题目：第 ... 题
- 核心卡点：...
```

每道题的标注放在该题后、下一题前。

基础题：

```markdown
**答案：** ...
**考点：** 一个最小必要考点
**解析：** ...
```

中难题：

```markdown
**答案：** ...
**核心考点：** 一个最关键突破口
**易卡点：** 学生最容易卡住或误判的地方
**关联考点：** 相关知识点；题型；方法
**解析：** ...
```

不同题之间用 `---` 分隔；不要在某节第一题前额外加分隔线，除非它确实承接上一题。

## 流程

1. 检查 Markdown 结构：标题、考试信息、题型标题、题目标题、已有答案、OCR 说明、图片引用。
2. 根据文件或用户说明确定官方题数；按现有题目标题风格切分题块。
3. 解题或推断答案。OCR 或小问有歧义时，保留假设和不确定说明。
4. 判断难度：
   - 基础题：定义、公式、一两步常规计算。
   - 中难题：参数、证明、多步几何、概率建模、新定义、函数/导数综合或常见陷阱。
5. 写卷首考点结构总览：一级模块 -> 二级考点 -> 涉及题目 -> 核心卡点。
6. 按基础题或中难题格式插入题后标注。
7. 题块之间插入 `---`。
8. 完成前做结构验证。

## 标签判断

- 基础题只给一个简洁 `考点`，避免堆 `核心考点/易卡点/关联考点`。
- 中难题的 `核心考点` 要写解题入口，不写泛泛章节名。
- `易卡点` 要点出学生具体失败方式：漏条件、方向用反、漏排除、模型错、把新运算当成熟悉运算、参数讨论不全。
- `关联考点` 可以列更大的知识树标签。
- 所有字段要短，便于课堂讲评扫描。

## 格式规则

- 保留原有图片、OCR 说明、章节标题和题干；只修明确的格式错位。
- 不保留末尾集中答案区；答案必须跟在题目后。
- 避免重写造成重复大标题。
- 避免控制字符，尤其是 `\t`、form-feed 或坏掉的 `\frac`。
- LaTeX 用正常命令：`\frac`、`\sqrt`、`\times`、`\prime`。
- 脚本写入 Markdown 时注意 raw string 或反斜杠转义。

## 验证

完成前确认：

- 官方题数 = 解析出的题块数。
- 每题都有 `**答案：**` 和 `**解析：**`。
- 每题有简单 `**考点：**`，或同时有 `**核心考点：**`、`**易卡点：**`、`**关联考点：**`。
- 识别出的相邻题块之间各有一条分隔线；不要用全文水平线总数替代题块检查。
- 没有重复大标题。
- 没有异常控制字符。
- 没有残留的独立 `答案解析与考点` 区。

可用检查脚本：

```python
from pathlib import Path
import re

text = Path("paper.md").read_text(encoding="utf-8")
questions = list(re.finditer(r"(?m)^###?\s*(\d+)[\.．]", text))
missing = []
for i, match in enumerate(questions):
    n = int(match.group(1))
    end = questions[i + 1].start() if i + 1 < len(text) else len(text)
    block = text[match.start():end]
    simple = "**考点：**" in block
    rich = all(x in block for x in ["**核心考点：**", "**易卡点：**", "**关联考点：**"])
    if "**答案：**" not in block or "**解析：**" not in block or not (simple or rich):
        missing.append(n)
control = [(i, repr(ch)) for i, ch in enumerate(text) if ord(ch) < 32 and ch != "\n"]
print({"questions": len(questions), "missing": missing, "control": control[:5]})
```
