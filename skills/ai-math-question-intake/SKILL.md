# 数学题目初加工

将材料变成可查找、能回源的题目记录；保持原件不变，不把识别或标签建议当成审定。

1. 确认材料范围、用途与可用权限，优先复用已有识别稿；使用远程识别或对外传送私人材料前取得相应授权。
2. 保留原件及来源、版本、页码 / 题号。识别公式和图片时与原件逐题对照；不确定处原样保留并标记，不猜补题干。
3. 给每道原题稳定 ID，记录完整题干、图片位置、答案 / 解析及其状态、专题与方法标签、来源定位和核对状态。一题可有多个标签，ID 不随分类变化。
4. 建立适合当前数据量的文件名、题目或正文检索入口；说明索引范围、更新时间、命中类型和来源路径。命中片段可能是正文或解析，不等同独立题数。
5. 用至少一条真实查询演示“关键词 → 候选 → 原题位置 → 图文核对”；说明可读性、缺图、识别和数学审校的未覆盖部分。

输出整理稿、题目台账和简短验收记录。分别标识“识别 / 原稿一致 / 数学审校”的实际状态；不要因文件存在、搜索命中或排版成功而宣布数学正确。
