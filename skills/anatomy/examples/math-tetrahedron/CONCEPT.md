# 正四面体平行截面：数学分支的小样

数学对象是主角，不使用机械底座与零件配额。复用 Anatomy 的 `iso`、`depthOf`、`fitProjection` 和 `pathOf` 投影工具；辅助标签、虚线及透明截面按数学用途绘制。

## 模型与推导

四顶点为 A(40,40,40)、B(40,-40,-40)、C(-40,40,-40)、D(-40,-40,40)，六棱长度均为 80√2。坐标单位为任意统一长度单位。

平面 z=t 与四条斜棱的交点，按截面顺序为 (40,t,t)、(t,40,t)、(-40,-t,t)、(-t,-40,t)。相邻边向量为 (t-40,40-t,0) 和 (-t-40,-40-t,0)，数量积为 0，边长分别为 √2(40-t)、√2(40+t)。在 -40<t<40 内，面积为 2(40-t)(40+t)=2(1600-t²)。

t=0 时为正方形；t=±40 时退化为一条棱；绝对值大于40时为空集。页面演示 t∈[-50,50]，原模型接受任意有限实数。本文件中的纯文本推导供源码阅读，正式页面使用原生 MathML 渲染公式。

## 交互与观察

- 数学控件：截面高度滑块与数值输入；预设正方形、长方形、退化、空集。
- 视角控件：方位角；重置视角只改相机。
- 讲解控件：观察、边长、面积；只改变讲解信息与图形辅助，不改数学状态。
- 两图联动：三维正交投影与截面所在平面的等比例正视图。前者显示位置关系，后者显示实际截面形状。
- 默认静止，无待机动画。原生控件支持键盘和触摸；具体实测范围由浏览器检查记录说明。

## 运行

```sh
node examples/math-tetrahedron/check.mjs
node examples/math-tetrahedron/build.mjs --out /path/to/output
```

输出 `tetrahedron-section.html`。脚本内联 kit、数学模块与展示代码，不包含远程字体、脚本或图片；最终 HTML 可直接离线打开。Node只在构建时需要，使用页面不需要Node。

此例用于验证数学模型、视角/步骤状态隔离、边界分类和离线渲染，不能作为其他题目的通用证明；也不提供 CAD 或打印工艺能力。


## 场景引用与标准作品包

`scenes.json` 同时供浏览器构建与作品清单使用；`#scene=square`、`rectangle`、`negative-rectangle`、`degenerate`、`empty` 能直接打开对应初始状态。未知场景有提示并恢复默认。用户随后改变参数不会回写清单。

运行 `node examples/math-tetrahedron/package.mjs --out /path/to/empty-package` 生成离线入口、可移植源码、模型检查证据及包外元数据草稿；其他验收暂为 pending。完成实际检查后，使用 `scripts/resources.py seal` 封存、`index` 入库、`resolve` 解析固定版本场景；详细流程见[资源规范](../../references/resource-package.md)。固定示例 ID 只代表此作品；新作品生成新 UUID，同一作品后续封存要升级版本。

## 题目绑定状态恢复

新版包默认版本 1.1.0，使用 `state-contract.json` 同时生成运行时和 manifest 1.1 契约。支持 `#scene=rectangle&state=<URL编码JSON>`，合并默认、场景、覆盖参数；非法链接提示并恢复默认。示例覆盖 t=10、视角130°、讲解步骤2时，真实模型面积3000。题目关联另存于资料库 `.bindings` 目录，不改变作品封存内容。
