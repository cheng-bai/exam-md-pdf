# 数学图形与交互设计

## 教学目标到视觉对象

优先把数学对象直接画出来。只在物理机制能保持数学对应关系时采用仪器隐喻，例如拉绳椭圆、圆锥截面实验、单位圆投影。不要为了风格给函数、集合或证明增加无关机器。

制作前用几行写明：原题/概念、变量与定义域、目标关系、允许操作、关键状态、观察问题、证明入口。学生需要发现什么应当能从一次明确操作看出。

| 主题 | 有效交互 | 关键校验 |
|---|---|---|
| 函数与参数 | 参数滑块、根/极值标记、分段显隐 | 定义域、不连续点断开、根的重数与临界值 |
| 圆锥曲线/轨迹 | 受约束拖点、固定量读数、轨迹开关 | 定义条件、圆/退化/空集、轨迹是否完整 |
| 向量/三角 | 分量、投影、单位圆与函数联动 | 方向、符号、弧度/角度、零向量 |
| 立体几何 | 视角、平面移动、辅助平面、独立截面图 | 真正空间求交、共面/平行/重合、遮挡 |
| 数列/概率 | 项数、参数、一次实验与统计对照 | 离散参数、精确值与模拟值、随机种子 |
| 分类讨论/证明 | 临界状态预设、逐步辅助构造 | 条件覆盖、边界归属、推理与观察分离 |

## 模型、视角、讲解分离

建议接口而非强制框架：

```js
const mathState = { t: 0 };           // 题目参数与对象
const viewState = { azimuth: 35 };    // 相机与显示比例
const lessonState = { step: 0 };     // 讲解阶段、提示、显隐
const result = derive(mathState);    // 纯函数，不访问 DOM/相机/时钟
render(result, viewState, lessonState);
```

参数定义必须先于控件设计。范围控件不是原题全域：如果只演示一个有界窗口，明确写出它。数学读数来自模型，不从屏幕像素反算；相机投影只决定画在何处。

需要缓动时，可缓动相机或数学参数本身；后者必须把实际显示的中间参数交给模型并同步读数。分类跳变和退化状态不得被视觉插值抹掉。

## 几何表示

- 二维默认等比例。只有教学任务明确需要不同比例时才允许，并标示比例；圆、垂直关系不能被误画。
- 三维数学坐标与投影坐标分开。正交投影仍可能改变屏幕夹角；角、长、面积从三维数学坐标计算。
- 理想线、平面、曲面不必有实体厚度。数学直线允许相交，截平面允许穿过实体，辅助平面允许半透明。细圆杆、薄板仅是展示方式时说明其厚度不属于原题。
- 区分线段、射线、直线及其可视窗口；延长线有不同线型。无穷远或超出窗口的交点不能默默删去，使用方向提示或状态说明。
- 曲线在不可定义点、渐近线和分支间断开；不能用一条折线跨越不连续点。采样密度服务于画面，数学判断另用解析或可靠数值算法。
- 明确可见边、隐藏边和教学高亮。选择透明/线框时在图例中说明；无需把所有边改成“不透明实体”以迁就机械绘图规则。
- 数学模型中的交点与实体制造中的碰撞不同；分开检查，不把有意相交视为制作失败。

## 标签、公式与颜色

点名/坐标靠近对应对象；少量引线可用于消除歧义，避免穿过主对象。长证明、条件和计算放到图旁或图下。拖动、缩放、手机状态下都要防止标签碰撞和裁切。

使用稳定的角色配色，例如主对象、辅助对象、截面；配合线型或图例，颜色数量按概念区分决定，不限制为一个高亮。优先让“发生变化的量”清楚可辨。

公式用真实渲染。离线 HTML 的 KaTeX/MathJax资源需本地携带或合法内联，保留许可；Node ESM 使用 KaTeX 的 `.mjs` 入口。简单公式可用原生 MathML，并实际检查目标浏览器。用户输入不得未经清理插入 HTML 或公式标记。

## 交互与教学

- 每个关键参数有可访问的名称、数值和单位；可精准到达临界值，必要时加预设按钮。原生 range 控件自动提供键盘入口。
- 拖点投影到允许的曲线、线段或平面，并提示约束。病态求交/无法唯一反投影时保留合法状态、提示原因；不要把屏幕拖拽当作无约束三维位置。
- 精确值、近似值和显示舍入分开。判断不能用保留两位小数后的数来决定相等或边界归属。
- 演示支持暂停、重置和步骤回退；“重置参数”“重置视图”按需要区分。步骤切换只增减对应辅助对象。
- 验证按钮、显隐和预设之间没有状态串扰；多实例时不要共享全局 ID、计时器或可变模型。
- 先观察，再给出解释与证明入口；“看起来”“采样符合”都不是证明。证据标为解析推导、数值验证或视觉观察。

## 与现有能力配合

复杂原题先复用当前可用的数学解题/审校能力，带入已核对的题干、条件、关键关系和临界值。分类讨论使用其真实边界生成预设。CAD 导出使用工程几何工具，动画视频使用视频流程；普通交互图不因此扩大为完整课件、网站或视频项目。
