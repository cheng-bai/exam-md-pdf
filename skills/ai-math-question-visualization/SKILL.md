# 数学题目可视化

以数学关系和教学目标为中心，不为动态效果牺牲正确性。保留完整题干和必要来源；已有答案可用时注明其审校状态。

1. 从原题写出“改变什么、保持什么、希望学生观察什么”。选择确有连续变化、约束或临界状态值得观察的题；静态图足够时不强制交互。
2. 建立变量、取值范围、约束、图形和读数的共同数学模型。把模型状态与视角 / 拖动画布分开；明确不合法和退化位置如何显示或限制。
3. 先做可运行小样，再补充题干、交互提示、结论与解析。保留重置入口；图形、符号、数值和解析必须一致。
4. 在真实浏览器检查初始、一般和边界状态，操作每个核心控件，检查公式实际渲染、页面尺寸及运行依赖；说明未测试的设备、离线或触屏情形。可视现象不能替代证明。
5. 输出本地入口、使用步骤、来源和版本、测试结果与未验证事项。归档、公开或发送前另行核对权限与隐私，不因本任务默认发布。

若环境已有适用的专业数学交互技能，可优先复用其实现和验收流程；本工作卡不依赖特定框架或服务。
