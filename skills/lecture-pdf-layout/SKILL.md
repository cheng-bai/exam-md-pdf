# 讲义 PDF 版式

## 概览

把数学内容做成清爽的 A4 中文讲义 PDF：单栏、密度适合用途、公式清晰、层级易辨。颜色、边框和教学栏目按已有风格及当次用途选择，不作为交付完整性的标志。

## 用途与内容边界

- 已确认内容只排版：冻结题号、顺序、题干、答案、来源；不重新选题、分类或补教学内容。只生成本次要求的版本。
- **教师阅读**：优先复用已有可读版式，长解析可跨页；紧凑不等于删步骤、合并长段或压小字号，不为固定页数牺牲讲评可用性。
- **学生练习**：题干紧凑、题后留白。未另指定时，选择/填空留约 1–2 行，解答题先留约 3 cm；依据步骤量和试排调整，明确这是起点而非每题固定高度。不默认添加答案或教师框。
- **打印讲评/批注**：保留清楚的分步解析和适量段间空白；用户指定留白、字号或黑白打印时优先执行。
- 几何图和统计图按标签可读性决定尺寸，下面的比例只作起点；拥挤时先放大或单独安排，不能为密度缩到看不清。

## 本地分类题集默认

适用于本地分类汇编，不强加给试卷原版、教材或黑白打印任务；当次用户要求优先。

- 标题用克制彩色层级：主标题/操作题型可用蓝色，考点专题/本题分析可用青绿色，正文黑色；避免整段彩色和装饰大框。
- 每题用紧凑“序号＋来源”行，题型由组标题呈现，默认不在序号后重复印【填空题】等形式标签，原题要求的标识保留。Markdown题目用五级、题内栏目六级；PDF字号单独设定。
- 紧凑阅读请求不默认加大块答题空白；保证字号、行距、图形标签可读。正文10.5pt、分析9.5–10pt可作试排起点，不固定页数或边距。
- 正文分类、可点击目录与书签共用映射，书签到操作题型；合订保留层级并验证目标页号。XeLaTeX引用/书签需足够编译遍数，首遍成功不等于目录生成。
- 授权的原本题分析完整保留，题干与分析清楚分开；不自动重写数学或加入答案。含分析版不能标为无提示练习。
- 小问标题与列表间留必要空行，预览确认各分析项没有合并。短题/四图选项尽量与题干同页；长题与长分析自然续页，不用不可分页大盒强包整题。

## 分类题集的学生版与教师版

仅在用户要求相应版本时应用；沿用已确认的分类、题号、来源和题干。

- 学生版保留逐题考点与必要原题图，默认隐藏答案、解析、解析辅助图和考点中的答案提示。用户已明确要求保留本题分析、方法提示或指定解析内容时依授权保留，并标明为含提示版；考点不得直接给出答案，除非用户明确要求。题解拼接图可裁出原题部分，但须回源核对所有标注。教师版保留原有答案、有效推导和解析图，缺失原解继续注明；缩图不能代替保留解析文字。
- 用户要求“图片小一些”时，双版分别设定保持比例的宽高上限，按图形标签的可读性调整；多图可采用两列或2×2，题干和必要题图尽量同页。参考一次A4建模题集：学生最大54×34mm、教师48×31mm，仅是试排起点，不作为通用上限。
- 长公式按语义或顶层等号选择少量换行，保留完整等式；不要机械拆开每个等号导致解析页数膨胀。圈号等符号以实际字体和编译日志核验，缺字时使用等价可渲染表示。
- 分版本比对题号集合、分类与考点。学生版除检索答案/解析字段外，还需目视题图和考点，识别图内辅助线、角度值或步骤泄漏；“未检出答案二字”不能单独证明无答案。教师版检查解析连续性、图文配对和长式跨页。
- 最后一次排版修改后更新预览，只以最新PDF页数对应的缩略图与抽查页作为验收证据，避免将旧页数残留预览算入本次检查。布局复核与数学审校分别报告。

## 本机长期署名规则

- 默认将 `chengbai` 作为页面不可见的署名：仅写入 PDF Author 元数据，不在页眉、页脚、正文、封面或背景新增 `chengbai` / `chengbai 数学讲义` 等可见文字。用户明确要求可见署名或指定其他标识时，以当次要求为准。
- 本规则中的“看不见的水印”采用文档元数据实现，可在文件属性中查看；不采用白字、透明文字或遮盖内容的做法。非 PDF 成品在格式支持时使用作者元数据，不支持时不强塞可见署名。
- `Kami` 仅可作为生成器或排版系统名称。输入资料中真实出版社、原作者及来源标识仍按来源保护规则保留；本规则只控制新生成成品的默认署名。
- 验收：页面预览及正文提取中没有新增的 `chengbai` 署名，PDF Author 为 `chengbai`（用户明确覆盖时除外）。

## 制作路径

- 来源和用途明确时直接处理；缺少会改变交付的信息时再澄清。读写 PDF 时配合 `pdf` skill，优先复用本任务已验证的源文件与构建流程，不强制迁移排版引擎。
- 新建 TeX 讲义且没有可复用版式时，可参考 `assets/lecture-handout-template.tex`，不必照搬其配色、栏目或命令。独立 `.tex` 默认使用宿主内置编辑器与编译工具；终端批量编译前确认 `xelatex` 的真实可执行路径。
- 只移除所用模板自身的样例品牌或占位署名，如“普通师匠 Hugo”“高中数学精编习题集（上海专版）”。输入资料中的真实出版社标识、发布者水印和必要来源信息默认保留，不得覆盖、模糊或重构；无法确认时列为待确认项。
- 导出后用 `pdfinfo` 等工具验证可打开、页数及 A4 尺寸，再实际查看渲染成品；文件存在、预览非空或模板标识清除都不能替代下列质量检查。

## 版式规则

- 页面：A4 纵向，单栏，密度和书写留白按上述用途选择。
- 边距：左右约 51pt，上 47pt，下 40pt。
- 字体：中文正文宋体风格，标题黑体风格，备注楷体风格，拉丁和数字用 Times New Roman。
- 颜色与块：默认克制、黑白打印仍可区分层级；细线或浅底可选，不强制题干、答案、解析分别使用三种颜色盒子。题干、选项和解析靠标题与间距清楚分开；同类内容的样式保持一致，不因Markdown段落边界只给第一小问着色。
- 用户要求题干彩框时，以完整题干为边界：题首、全部小问、表格和原题图均在同一题干容器内，答案、考点与解析在框外。能放下一页的题干尽量整体移动；超高题干允许续页并检查底色延续、内边距及末行，不把全题解析也锁进不可分页盒。
- 图片：讲义插图默认居中，最大宽度约版心 0.72、最大高度约正文高度 0.27；统计图、几何图不应撑成半页大图，除非用户明确要求看图优先。
- 解析依赖图形关系且现有题图不足时，按推导补画清晰的矢量辅助图，原题图与解析图分开保留。核对坐标、共线、交点、虚实线及标签；特殊参数示意须注明取值，不以特例图替代一般证明。只排版且没有补图授权时，记录缺图交回内容环节；学生版不自动携带解析辅助图。
- `课堂内容概要` 要比解答框更克制：灰黑、浅灰或无背景、细分隔线、加粗标签、紧凑间距。
- 数学：短表达式用行内 math；长公式、对齐推导、分段、方程组、最终强调用 display math。
- 结构：保留题号、小问和`解`/`证明`等必要层级；解析按主要推理动作分段，关键推导独立成行，自动折行不能代替逻辑分段。难度、`点拨`/`高观点`/`方法总结`仅在原稿已有、用户要求或确有用途时保留，不默认添加。
- 大题题头只保留序号（如 `17.`），不把分值分配写进题头；用户明确要求保留分值或原卷格式时从其要求。
- 大题考点按小问逐项标注，如“（1）…；（2）…”，顺序与题目一致；不用一条笼统考点代替小问对应关系。
- 答案摘要左对齐，不用两端对齐或弹性间距把短答案拉开；每个小问的答案连同标点作为不可拆分的短段，避免“；”或句号单独落到下一行。
- 页脚页码可保留；用户要求完全干净页面时再移除。

## 可选模板命令

仅使用上述TeX模板时按需调用，不要求每题出现这些栏目。

```tex
\difficulty{3}
\begin{answerbox} ... \end{answerbox}
\point{点拨：...}
\gaoguan{...}
```

## 质量门槛

- **分开验收**：结构与版式检查证明内容可读、未丢失；内容检查证明题解足以回答题问。版式技能不代替数学审校；只排版时若发现缺解、跳步或越出高中方法边界，记录并交回内容环节，不擅自改写，也不以渲染成功宣布“详细讲评通过”。
- 第一页必须是实际教学内容，不做营销封面，除非用户明确要求。
- 可打印、可检查：无文字重叠、无缺字方框、无误入模板样例品牌；真实来源标识按上面的来源保护规则处理。
- 逐题核对小问及解答是否完整呈现；长解析按推理动作分段，分类、端点和最终结论可定位。同类小问样式一致，不把“有色块”“公式无错”作为内容充分的证据。
- 内容超过一页时允许自然分页；若使用TeX模板的长 `answerbox`，须启用 `breakable`，不要外套 `minipage` 等不可分页容器。其他引擎检查对应容器的分页与溢出，不为保持整题同页强压内容。
- 查看渲染后的成品；存在图片密集页和解析密集页时各至少抽查一页，并检查受改动的分页。记录总页数、已检页码、缩略图/原尺寸及问题；生成预览图片不等于查看，抽查不得称逐页检查。
