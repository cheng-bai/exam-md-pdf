# 数学试题分类汇编

围绕教学任务组织题目，以同一份可追溯母集生成不同用途的版本，而非分别维护多份题干。

1. 确定卷次、题目范围、读者和交付用途。保留来源、图文、原题号、稳定 ID、答案解析与核对状态；复用可靠原稿，不擅自补造缺失信息。
2. 先按专题和数学任务 / 方法分类，再处理题型与难度；允许一题跨类展示，但保留相同原题 ID。难度标注应说明依据，不冒充学生实测。
3. 冻结本批母集和分类清单，从同一底稿生成所需版本：学生教学版保留解题所需图文且不泄露答案，教师版按需求保留题后答案解析。特殊平台匹配版按其明确规则另做，并说明缺图等使用限制。
4. 对账来源、题号、分类和版本：分别统计专题展示条目与不同原题 ID；检查缺题、重复、答案泄露、图片公式、选项、分页和空白页。对疑点保留记录并回源核实。
5. 修改时回到母集，重建受影响版本并复查。逐项报告自动检查、视觉检查、数学审校和平台实测的覆盖范围；未实际上传或测试的平台不声称识别成功。

输出分类目录、汇编文件、逐题台账及验证 / 未决事项。交叉展示不是新增原题，结构通过不等于逐题数学正确。
