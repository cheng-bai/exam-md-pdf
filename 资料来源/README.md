# 资料来源库

用途：按资料提供者、机构或项目品牌保存公式识别稿、OCR 语料、历史版本和研发过程资料。

这里保存的是后续制作试卷、讲义和汇编时使用的来源材料，不等同于已经审校完成的正式成品。

## 来源分类

- `学科网资料/`：学科网讲义及其一轮、二轮、冲刺课程识别稿。
- `承白资料/`：承白及项目组制作、重组、注释和研发的资料。
- `其他教师资料/`：Q 老师、sun、小火车及其他教师来源资料。
- `EduVault资料/`、`xdf资料/`、`zqh资料/`、`鱼老师资料/`、`帅琪数学资料/`、`范老师资料/`：来源明确的外部资料。
- `教辅教材资料/`：教材、教辅书和公式手册识别稿。
- `试卷与汇编资料/`：区域考试、模拟卷、预测卷和试卷汇编来源稿。
- `来源待确认资料/`：暂时不能可靠确认作者或机构的资料。
- `历史说明/`：目录调整前的说明文件，仅用于追溯。

## 使用规则

- 优先保留资料原有名称和内部结构，不随意合并不同版本。
- 承白及项目组制作的研发稿统一归入 `承白资料/`。
- 来源不明确时先放入 `来源待确认资料/`，不要凭印象署名。
- 整理成正式成品后，分别归档到 `exams/`、`handouts/` 或 `collections/`。
- 移动 Markdown 时必须同步检查仓库内相对图片引用。
