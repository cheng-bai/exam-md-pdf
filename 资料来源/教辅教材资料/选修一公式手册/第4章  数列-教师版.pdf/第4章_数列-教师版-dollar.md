## 第4章 数列

### 4.1 等差数列

#### 4.1.1 等差数列及其通项公式

1. 等差数列的递推公式为 ${a}_{n} = {a}_{n - 1} + d\left( {n \geq  2, n \in  {\mathbf{N}}^{ * }}\right)$ .

2. 给定一个数列 $a, A, b$ ，若其为等差数列，则 $\frac{a + b}{2}$ 叫做 $a$ 与 $b$ 的等差中项.

3. 等差数列 $\left\{  {a}_{n}\right\}$ 的通项公式为 ${a}_{n} = {a}_{1} + \left( {n - 1}\right) d$ ，也可以变式为 ${a}_{n} = {a}_{m} + \left( {n - m}\right) d$ .

#### 4.1.2 等差数列的前 $n$ 项和

1. $\sum$ 称为求和符号,例如 ${S}_{n} = \mathop{\sum }\limits_{{i = 1}}^{n}{a}_{i} = {a}_{1} + {a}_{2} + \cdots  + {a}_{n}$ .

2. 可用 倒序相加 法推导得等差数列的前 $n$ 项和公式: ${S}_{n} = \frac{n\left( {{a}_{1} + {a}_{n}}\right) }{2} = n{a}_{1} + \frac{n\left( {n - 1}\right) }{2}d = \; \frac{d}{2}{n}^{2} + \left( {{a}_{1} - \frac{d}{2}}\right) n$

### 4.2 等比数列

#### 4.2.1 等比数列及其通项公式

1. 等比数列的递推公式为 ${a}_{n} = {a}_{n - 1} \cdot  q\left( {n \geq  2, n \in  {\mathbf{N}}^{ * }}\right)$ .

2. 给定一个数列 $a, A, b$ ,若其为等比数列,则 $\pm  \sqrt{ab}$ 叫做 $a$ 与 $b$ 的等比中项.

3. 等比数列 $\left\{  {a}_{n}\right\}$ 的通项公式为 ${a}_{n} = {a}_{1}{q}^{n - 1}$ ，也可以变式为 ${a}_{n} = {a}_{m}{q}^{n - m}$ .

#### 4.2.2 等比数列的前 $n$ 项和

1. 当 $q \neq  1$ 时,可用 错位相减 法推导得等比数列的前 $n$ 项和公式: ${S}_{n} = \frac{{a}_{1}\left( {1 - {q}^{n}}\right) }{1 - q} =$

$\frac{{a}_{1} - {a}_{n}q}{1 - q} = \frac{{a}_{1}}{1 - q} - \frac{{a}_{1}}{1 - q}{a}^{n}$ ; 当 $q = 1$ 时, ${S}_{n} = n{a}_{1}$ .

2. 若 ${S}_{n} = A + B{q}^{n}$ 为等比数列前 $n$ 项和,则 $A + B = 0$ .

3. 无穷等比数列各项的和:

对于首项为 $a$ 、公比为 $q$ 的等比数列: ${a}_{n} = a{q}^{n - 1}\left( {n \in  {\mathbf{N}}^{ * }}\right)$ ，当 $0 < \left| q\right|  < 1$ 时，此数列的前 $n$ 项和 ${S}_{n} = \frac{a\left( {1 - {q}^{n}}\right) }{1 - q}$ 随着 $n$ 无限增大, ${S}_{n}$ 的值越来越趋近于 $\frac{a}{1 - q}$ ,记作无穷等比数列各项的和为 $\mathop{\lim }\limits_{{n \rightarrow   + \infty }}{S}_{n} = \mathop{\sum }\limits_{{i = 1}}^{{+\infty }}a{q}^{i - 1} = l\frac{a}{1 - q}.$

#### 4.2.3 等差等比数列的其他性质

1. 若两个等差数列 $\left\{  {a}_{n}\right\}$ 和 $\left\{  {b}_{n}\right\}$ ，它们的前 $n$ 项和分别为 ${S}_{n}$ 和 ${T}_{n}$ ，则 $\frac{{a}_{m}}{{b}_{m}} = \frac{{S}_{{2m} - 1}}{{T}_{{2m} - 1}}$ ；

2. 若等差数列的项数为 ${2n}\left( {n \in  {\mathbf{N}}^{ * }}\right)$ ，则 ${S}_{2n} = n\left( {{a}_{n} + {a}_{n + 1}}\right)$ ， ${S}_{\mathrm{\text{ 偶 }}} - {S}_{\text{ 奇 }} = {nd}$ ， $\frac{{S}_{\text{ 奇 }}}{{S}_{\text{ 偶 }}} = \frac{{a}_{n}}{{a}_{n + 1}}$ ；

3. 若等差数列的项数为 ${2n} - 1\left( {n \in  {\mathbf{N}}^{ * }}\right)$ ,则 ${S}_{{2n} - 1} = \left( {{2n} - 1}\right) {a}_{n}\;,{S}_{\text{ 奇 }} - {S}_{\text{ 偶 }} = {a}_{n}\;,\frac{{S}_{\text{ 奇 }}}{{S}_{\text{ 偶 }}} = \; \frac{n}{n - 1}$

4. 在等差数列 $\left\{  {a}_{n}\right\}$ 中，若 ${a}_{n} = m,{a}_{m} = n\left( {m \neq  n}\right)$ ，则 ${a}_{m + n} = 0$ ；

5. 在等差数列 $\left\{  {a}_{n}\right\}$ 中，前 $n$ 项和为 ${S}_{n}$ ，若 ${S}_{n} = m$ ， ${S}_{m} = n\left( {m \neq  n}\right)$ ，则 ${S}_{m + n} =  - \left( {m + n}\right)$ ；

6. 在等差数列 $\left\{  {a}_{n}\right\}$ 中，前 $n$ 项和为 ${S}_{n}$ ，若 ${S}_{n} = {S}_{m}\left( {m \neq  n}\right)$ ，则 ${S}_{m + n} = 0$ ；

7. 既成等差数列又成等比数列的连续三个数，必构成非零 常数列 .

8. 等比数列 $\left\{  {a}_{n}\right\}$ 中,

(1)若 ${a}_{1} > 0, q > 1$ 或 ${a}_{1} < 0,0 < q < 1$ ，则数列 $\left\{  {a}_{n}\right\}$ 是严格增数列；

(2)若 ${a}_{1} > 0,0 \leq  q < 1$ 或 ${a}_{1} < 0, q > 1$ ，则数列 $\left\{  {a}_{n}\right\}$ 是严格减数列；

(3)若 $q = 1$ ___，则数列 $\left\{  {a}_{n}\right\}$ 是常数列；

(4)若 $q < 0$ ，则数列 $\left\{  {a}_{n}\right\}$ 是摆动数列.

9. 正数列 $\left\{  {a}_{n}\right\}$ 成等比充要条件是数列 $\left\{  {{\log }_{x}{a}_{n}}\right\}  \left( {x > 0, x \neq  1}\right)$ 成等差数列;

10. 等比数列的前 $n$ 项和公式可写成 ${S}_{n} = k{q}^{n} - k\left( {k \neq  0, k\text{ 为常数, }q \neq  0,1}\right)$ ,其中 $k = \frac{{a}_{1}}{q - 1}$ .

### 4.3 数列

#### 4.3.1 数列的概念与性质

1. 按照一定次序排列的一列数称为一个数列.

2. 函数思想: 数列可以看成以正整数集(或其子集) 为定义域的函数 ${a}_{n} = f\left( n\right)$ ，求数列的最值通常可以从函数的角度出发思考，利用 单调性 是最核心最基本的方法.

3. 项数有限的数列叫做 有穷 数列；项数无限的数列叫做 无穷 数列.

4. 数列的单调性:

从第2项起,每一项都不小于其前一项的数列 $\left\{  {a}_{n}\right\}$ 叫做增数列, $\;{a}_{n + 1} \geq  {a}_{n}\left( {n \in  {\mathbf{N}}^{ * }}\right)$ 恒成立. 从第2项起,每一项都大于其前一项的数列 $\left\{  {a}_{n}\right\}$ 叫做 严格增 数列, ${a}_{n + 1} > {a}_{n}\left( {n \in  {\mathbf{N}}^{ * }}\right)$ 恒成立. 从第2项起,每一项都不大于其前一项的数列 $\left\{  {a}_{n}\right\}$ 叫做减数列, $\;{a}_{n + 1} \leq  {a}_{n}\left( {n \in  {\mathbf{N}}^{ * }}\right)$ 恒成立. 从第2项起,每一项都小于其前一项的数列 $\left\{  {a}_{n}\right\}$ 叫做 $\text{ 严 }$ 格减数列, ${a}_{n + 1} < {a}_{n}\left( {n \in  {\mathbf{N}}^{ * }}\right)$ 恒成立. 增数列和减数列统称为 单调 数列. 各项均相等的数列叫做 常 数列.

#### 4.3.2 利用递推公式表示数列

1. 如果数列 $\left\{  {a}_{n}\right\}$ 的任一项 ${a}_{n}$ 可由其前一项 ${a}_{n - 1}$ (或前几项)通过一个公式来表示，那么这个公式就叫做这个数列的一个 递推公式 . 它也是表示数列的一种方法. 有时数列的通项公式不容易被发现, 但可通过数列的递推关系来描述该数列.

#### 4.3.3 求数列通项公式的方法总结

1. 形如 ${a}_{n} - {a}_{n - 1} = f\left( n\right) \left( {n \geq  2}\right)$ 或 ${a}_{n + 1} = {a}_{n} + f\left( n\right)$ 的递推公式,可用 累加 法求其通项公式.

2. 形如 $\frac{{a}_{n}}{{a}_{n - 1}} = f\left( n\right) \left( {n \geq  2}\right)$ 或 ${a}_{n} = f\left( n\right) {a}_{n - 1}$ 的递推公式,可用 累乘 法求其通项公式.

3. 构造新数列:

类型 $1 : {a}_{n + 1} = p{a}_{n} + q$ (其中 $p, q$ 均为常数, $p \neq  0,1$ ). 转化为 ${a}_{n + 1} + \lambda  = p\left( {{a}_{n} + \lambda }\right)$ ,其中 $\lambda  =$

类型2: ${a}_{n + 1} = p{a}_{n} + {an} + b\left( {p \neq  1,0, a \neq  0}\right)$ ,转化为 ${a}_{n + 1} + {\lambda n} + \mu  = p\left( {{a}_{n} + {\lambda n} + \mu }\right)$ .

类型3: ${a}_{n + 1} = \frac{c{a}_{n}}{b{a}_{n} + d}$ ,两边取 倒数 后转化为 ${a}_{n + 1} = p{a}_{n} + q$ 型.

类型4: ${a}_{n + 1} = p{a}_{n}^{r}\left( {p > 0,{a}_{n} > 0}\right) ;{a}_{n + 1}^{q} = p{a}_{n}^{r}$ ,两边取 对数 后转化为 ${a}_{n + 1} = p{a}_{n} + q$ 型.

类型5: ${a}_{n + 1} = p{a}_{n} + {q}^{n}$ (其中 $p, q$ 均为常数, $p \neq  0,1, q \neq  0,1$ ),等式两边同除以 ${q}^{n + 1}$ (转化为类型1) 或 ${p}^{n + 1}$ (使用累加法) 后求解.

类型6: $p{a}_{n + 1}{a}_{n} = {a}_{n} - {a}_{n + 1}$ 或 ${a}_{n + 1}{a}_{n} = p{a}_{n} - q{a}_{n + 1}$ ,两边同除以 ${a}_{n + 1}{a}_{n}$ 进行转化.

4. 阶差法: ${a}_{n} = \left\{  \begin{array}{ll} {a}_{1}, & n = 1 \\  {S}_{n} - {S}_{n - 1}, & n \geq  2, n \in  {\mathbf{N}}^{ * } \end{array}\right.$

#### 4.3.4 求数列前 $n$ 项和的方法总结

1. 常用的求和方法有: 公式法、倒序相加法、错位相减法、裂项相消法、分组求和法等.

2. 裂项相消法常用公式:

① $\frac{1}{n\left( {n + 1}\right) } = \frac{1}{n} - \frac{1}{n + 1}\;;\;$ ② $\frac{1}{n\left( {n + k}\right) } = \frac{1}{k}\left( {\frac{1}{n} - \frac{1}{n + k}}\right) \;;$

③ $\frac{1}{\left( {{2n} - 1}\right) \left( {{2n} + 1}\right) } = \frac{1}{2}\left( {\frac{1}{{2n} - 1} - \frac{1}{{2n} + 1}}\right) \;;\;$ ④ $\frac{1}{\sqrt{n} + \sqrt{n + 1}} = \sqrt{n + 1} - \sqrt{n}$ .

### 4.4 数学归纳法

#### 4.4.1 数学归纳法

1. 由特殊到一般的推理方法，叫做 归纳法 .

2. 一般地，证明一个与正整数 $n$ 有关的命题，可按下列步骤进行:

(1)证明当 $n$ 取第一个值 ${n}_{0}\left( {{n}_{0} \in  {\mathbf{N}}^{ * }}\right)$ 时命题成立；

(2)假设当 $n = k\left( {k \geq  {n}_{0}, k \in  {\mathbf{N}}^{ * }}\right)$ 时命题成立，证明当 $n = k + 1$ 时命题也成立.

那么命题对从 ${n}_{0}$ 开始的所有正整数 $n$ 都成立. 这种证明方法叫做 数学归纳 法.
