**答案：** $\dfrac12$。

**解析：** $|\vec a|^2=5$，由 $(\vec a+\vec b)\cdot\vec a=10$ 得 $\vec a\cdot\vec b=5$。故 $\cos\langle\vec a,\vec b\rangle=\dfrac5{\sqrt5\cdot2\sqrt5}=\dfrac12$。

**考点：** 向量数量积与夹角。

2、[2023.10 泰贤月考 7] 已知向量 $\overrightarrow{a} = \left( {\sin {2x},2\cos x}\right) ,\overrightarrow{b} = \left( {\sqrt{3},\cos x}\right)$ ，则函数 $f\left( x\right)  = \overrightarrow{a} \cdot  \overrightarrow{b} - 1, x \in  \left\lbrack  {-\frac{\pi }{2},\frac{\pi }{2}}\right\rbrack$ 的严格增区间为___.

**答案：** $\left(-\dfrac\pi3,\dfrac\pi6\right)$。

**解析：** $f(x)=\sqrt3\sin2x+\cos2x=2\sin\left(2x+\dfrac\pi6\right)$。令 $f'(x)>0$，即 $\cos\left(2x+\dfrac\pi6\right)>0$，并与定义域取交集。

**考点：** 数量积、三角恒等变换、单调性。

3.【2023.11 高桥高三期中 8】在 $\bigtriangleup  {ABC}$ 中， $C = \frac{\pi }{3}$ ，则 $\cos A + \cos B$ 的取值范围是___.

**答案：** $\left(\dfrac12,1\right]$。

**解析：** $A+B=\dfrac{2\pi}{3}$，故 $\cos A+\cos B=2\cos\dfrac{A+B}{2}\cos\dfrac{A-B}{2}=\cos\dfrac{A-B}{2}$。又 $\left|\dfrac{A-B}{2}\right|<\dfrac\pi3$。

**考点：** 和差化积、三角形内角范围。
