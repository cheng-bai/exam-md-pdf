# 数学解析语言风格

目标是写出可核验、可讲解、适合高中书面作答的解析。简洁是删去空话和重复，不是压缩有效步骤；用户要求详细作答或教师讲评时，不能以答案核对稿代替完整讲解。借鉴《建平中学高三2026学年第一学期10月月考卷终稿（答案）》的表达，不模仿其中的数学错误、栏目混排或省略缺口。这是表达层技能，不接管解题、题库、审校或文档制作流程。

## 适用与优先级

- 本机用户要求今后新写或润色高中数学解析默认采用此风格；当前请求明确指定的篇幅、对象、方法和其他文风优先。只要答案就只给答案；只解释某一步就对准该步，不重做全题。
- 完整题解保留完整原题及必要图形；局部追问不重复整题。题源、学生版答案隔离、学情证据和格式要求沿用主任务，不因模仿文风改变。
- 纯转录、原解析提取、只审校不改写、只改版式时，不套用文风重写。保留原解的任务如需补解或纠错，明确区分原文与新写内容。已归档作品不追溯改造。

## 写法

### 1. 用文字推动推理，不评价自己的解法

围绕数学对象组织短句，形成“依据 → 操作或转换 → 所得结论”。按实际作用使用“由题意”“由……定理”“设”“令”“因此”“即”“化简得”“当……时”“综上”，不为模仿而在每行重复“所以”。

避免“本题巧妙地运用”“核心突破在于”“我们不难发现”等无实质内容的评价。不能只把公式用连接词串起来：凡是不直接的推出，仍应交代中间关系或依据。“显然”“易得”“即可”不得遮住关键论证。

### 2. 先带读者读懂，再把条件变成操作

对抽象题目的完整讲解，不能把精简的书面作答当作唯一阅读层。先解释题目中的对象、限制和所求各是什么意思，让读者分清“给了什么、没给什么、要求每次成立还是某次成立”；再把实际使用的条件逐条连到具体变形或图形上。只说“由题意”后直接报出内分、作垂线、构造函数等结论，不算解释了入口。局部追问、简单题或只要答案时仍不强加读题栏目。

在主要转换处说清“这个条件在说什么 → 为什么考虑这一步 → 变成了什么可用关系”。如“值域恰为两个元素，要求两种函数值都被取到，因此分成的两组均非空”。解释对应本题对象和限制，不只报“数形结合”“整体思想”等标签；新符号和辅助构造不能突然出现而没有来历。

如果题意本身过于抽象，可先展开递推的第一步、取一个有代表性的具体例子，或使用有准确对应关系的类比。说明例子哪些是另设的数据、类比对应原题的哪些量；类比只帮助理解，不暗加条件、不承担一般证明。讲解使用高中课程内知识与方法，不为缩短篇幅用大学概念或定理替代高中论证；尚未找到合适路线时如实说明，不把术语换名冒充高中解法。

### 3. 关键选择说明来历，常规计算适度合并

常规求导、代入、整理可连写；分类依据、符号选择、量词次序、反证矛盾点、构造与放缩的目的应展开。一个主要推理动作一个短段或公式组，不把每次算术操作机械拆成步骤。

对难想到的构造或辅助不等式，写清它要保住哪些条件、希望得到什么形式，以及选择为何有效。先解释识别依据，再给构造并验证；不能把回顾性的理由伪装成作者或学生真实的思考经历。难题确需直观辅助时，先给短例子或图示，再完整证明，不让比喻代替论证。

### 4. 区分探索语言与证明语言

“尝试”“猜测”“尽可能大”可用于解释寻找路线；正式证明落实为可核验的不等式、分类或构造。

- 最小值、最少个数：排除更小的可能，再证明候选可达到；严格界不能擅写为可取得的最大值。
- 存在、存在唯一、任意、恒成立：保留其量词含义，给出相应构造、唯一性、一般证明或反例；不能互换逻辑对象。
- 反证：交代假设与冲突的具体条件，不只写“显然矛盾”。反推候选后须验证满足原条件；必要条件不是存在性证明。

## 按交付物控制层次

- **普通单题**：完整题目后直接解答；真正有帮助时，在解答前补一段短分析。不固定追加方法总结、易错点或练习。
- **基础题**：必要定义、计算和结论即可，不为凑栏目写重复分析。
- **详细作答与教师讲评**：按小问和主要推理动作分段；在本题真正需要处保留读题入口、方法选择、可复算的中间关系、分类与端点验证。新定义说明取值区间与量词，新参数说明用途，关键公式说明由哪些方程推出；不能只加标题或把一段压缩证明拆行冒充详解。是否增加分析栏取决于内容，不固定栏目数量或每题篇幅。
- **教学分析与讲解网页**：先让读者理解条件与目标，再说明“哪个条件提示哪个动作、为何接近目标”。不能只附一段概括分析后仍让主要构造突然出现；无需重复全部运算，也不要只列操作清单。书面作答可以简洁，但不能挤掉读者理解题意和方法来历所必需的说明。
- **正式解答**：给可独立成立的证明与计算，不能依赖分析栏补齐逻辑。用推导结束后的具体答案收束；涉及等号、范围、端点或构造时交代成立情况。
- **已有教师版模板**：保留主任务要求的答案、考点、易卡点等字段；上述规则只约束解析文字，不新增一套重复栏目。学生版不因这套规则泄露答案。
- 若使用【答案】【分析】【详解】，答案放结论，分析放入口与理由，详解放完整论证；不把长证明放在答案里、再以“略”替代实际解答。

需要校准措辞或查看对照案例时读 [references/examples.md](references/examples.md)；日常简短解析无需预读。该文件亦说明学习样本与反例的边界。

## 交付前检查

分别检查数学正确性、讲解充分性与最终阅读结构；一项通过不能替代另一项。先按主解题技能检查数学正确性，再检查表达。

- 读者能否定位每次主要转换的根据？是否把不易推出的结论藏在“即”“所以”后？
- 对抽象题，未见过解法的读者能否先说清题目究竟要求什么？实际用到的条件是否有明确转化，新符号与构造是否解释来历？是否越出高中知识范围？
- 方法或构造难想到时，有无一句具体理由？是否重复题干、重复分析或加入无用途的评价？
- 是否写清本题涉及的定义域、除法条件、符号、分类、端点、等号与达到性？不涉及者不硬加栏目。
- 是否把猜测当证明、把必要当充分，或把存在性陈述误当条件命题？先核对题目所求对象及适用教材定义，再检查答案的对象类型和结论；不得擅自给题问增添限定词。例如题问“投影”时，不能未经核实改成“数量投影”。
- 详细讲评能否让未见过解法的高中读者逐步复算？重点查新定义、参数引入、关键公式的中间关系与高中方法边界；若只剩答案与跳步，先补内容，不靠换行补救。
- 最终交付中，各小问、分类和关键推导能否直接定位？长段是否按推理动作分开？PDF或网页还需由对应版式流程检查实际成品，不能只看Markdown源或“公式已渲染”就判定讲评可用。
